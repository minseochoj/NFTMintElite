# NFTMintElite

A simple NFTMintElite Gateway for Conditional token transfers.

With NFTMintElite, you get a lightweight tool that stays out of your way.

**What you get**

- A simple NFTMintElite Gateway for Conditional token transfers

## Key Features

- A simple NFTMintElite Gateway for Conditional token transfers

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTMintElite.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NFTMintElite is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
